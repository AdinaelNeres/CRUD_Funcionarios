# CRUD de fucionários.

# Sobre

    O projeto consiste em um sistema de controle de cadastro de funcinários de uma empresa. Nele você pode incluir novos funcionários, consultar o quadro de funcionários já cadastrados, atualizar as informações de cada funcionário e também excluor um funcionário da base se for o caso.

    No desenvolvimento do projeto foram aplicados conceitos de python para a comunicação com o usuário e manipulação dos dados fornecidos pelo mesmo. Além disso, foi implementado o uso do SQL Server como banco de dados principal para o armazenamento das informações.

## Funcionalidades

- Cadastro de funcionários.
- Consulta do quadro de funcionários.
- Atualizar funcionário.
- Excluir funcionário.

## Tecnologías

- Python
- SQL Server

# Dicas de uso

    Antes de rodar o código, acesse o arquivo "config.exemplo.jsn"n e altere as informações do 'Driver' e "Server" de acordo com a sua máquina. Após alterar as informações renomei o arquivo para 'config.json' e pode rodar o códgio normalmente.
